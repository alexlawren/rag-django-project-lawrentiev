\#  локальная RAG-система для анализа документов 🧠📄



!\[Python](https://img.shields.io/badge/Python-3.11-blue.svg)

!\[Django](https://img.shields.io/badge/Django-4.x-green.svg)

!\[PyTorch](https://img.shields.io/badge/PyTorch-2.x-orange.svg)



Этот проект представляет собой полнофункциональное веб-приложение для интеллектуального анализа текстовых документов, построенное на архитектуре \*\*Retrieval-Augmented Generation (RAG)\*\*. Система позволяет пользователям загружать документы и задавать по ним вопросы на естественном языке, получая точные, фактологически обоснованные ответы, сгенерированные \*\*полностью локально\*\* на вашем компьютере.

\### ✨ Ключевые особенности



\- \*\*Полная локальность и конфиденциальность:\*\* Все модели и данные обрабатываются на вашей машине и никогда не покидают ее пределов.

\- \*\*Поддержка разных форматов:\*\* Анализируйте `.pdf`, `.docx` и `.txt` файлы благодаря библиотеке `Unstructured`.

\- \*\*Высокая точность ответов:\*\* Механизм RAG предотвращает "галлюцинации" (выдумывание) языковой модели, заставляя ее отвечать строго на основе фактов из документа.

\- \*\*Продвинутый поиск:\*\* Реализован двухэтапный retrieval-пайплайн:

&nbsp; 1.  \*\*Быстрый поиск (Retriever):\*\* Находит широкий круг кандидатов с помощью векторного поиска в `ChromaDB`.

&nbsp; 2.  \*\*Точное переранжирование (Re-ranker):\*\* Оценивает кандидатов с помощью `Cross-Encoder` для выбора самых релевантных.

\- \*\*Интуитивно понятный интерфейс:\*\* Простой и чистый веб-интерфейс, реализованный на Django.

\### 🛠️ Технологический стек



| Категория | Технология | Описание |

| :--- | :--- | :--- |

| \*\*Бэкенд и UI\*\* | `Python 3.11` | Основной язык программирования. |

| | `Django` | Веб-фреймворк для реализации интерфейса и API. |

| \*\*Нейросети (RAG)\*\* | `PyTorch` | Фундаментальная библиотека для машинного обучения. |

| | `Hugging Face Transformers` | Для загрузки и работы с LLM и Cross-Encoder. |

| | `Sentence-Transformers` | Для создания векторных представлений (эмбеддингов). |

| | `ChromaDB` | Локальная векторная база данных. |

| \*\*Обработка данных\*\* | `Unstructured` | Для извлечения текста из различных форматов файлов. |

| | `NLTK` | Для сегментации текста на предложения. |
